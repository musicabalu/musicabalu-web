# Manual de Estilo Visual (Branding)

Este documento centraliza todas las decisiones de diseño para garantizar la coherencia visual en toda la plataforma.

## 1. Tipografías
*   **Títulos y Encabezados:** `Quicksand` (Medium/Bold). Transmite cercanía, infancia y modernidad.
*   **Textos de párrafo (Cuerpo):** `Montserrat` (Regular/Light). Excelente legibilidad en pantallas para textos largos.

## 2. Paleta de Colores Corporativos
Estos son los valores exactos (Hexadecimales) que se usarán en nuestras variables de Vanilla CSS:

*   **Azul Principal:** `#00B2E3` (Color de marca, botones principales).
*   **Rosa:** `#f4436c` (Acentos, llamadas a la acción secundarias).
*   **Amarillo:** `#FED65E` (Detalles, estrellas, avisos amables).
*   **Verde:** `#AADB1E` (Confirmaciones, éxito).
*   **Gris oscuro:** `#3C4040` (Color exclusivo para textos, evita el negro puro que cansa la vista).
*   **Fondos:** Se utilizarán variaciones muy claras de gris o blanco puro (`#FFFFFF`) para mantener la interfaz limpia.

## 3. Logotipo
*   **Ubicación:** El archivo maestro actual se encuentra referenciado como `logos/PNG/logo_slogan.png`.
*   **Regla de uso:** Se debe usar la versión sin fondo (PNG transparente) en la barra de navegación (Header) de todas las páginas.
